A vs C for redness — what's the real difference?

Redness is diffuse (spreads across skin), not spotty like acne. That changes which approach wins.

A — Zone Blending
Scenario: left cheek very red, right cheek clear, nose medium
✓ Clear asymmetry — left cheek clearly redder
✓ Zone ownership is predictable
⚠ Seam at zone boundary can look unnatural
⚠ Nose redness driven only by front angle — misses side contributions
C — Weighted Composite
Same scenario: left cheek very red, right cheek clear, nose medium
✓ No seam — completely smooth gradient
✓ Every vertex weighted by how visible it is from each angle
✓ Nose gets front + slight side contributions naturally
⚠ High redness on one side bleeds slightly to the other
⚠ Asymmetry slightly softer / less dramatic
Key insight for redness

Redness is a diffuse condition — it's about skin tone across a region, not a precise spot location. Option C's bleed effect is actually realistic: a cheek that's red in the side photo probably has some redness extending toward the nose too. Option A would be better for acne spots (precise location matters) but C is more physically truthful for redness.

★

Hybrid (recommended)

Use C (weighted composite) for redness and under-eye bags. Use A (zone blending) for acne spots. Each condition picks the right strategy.

C

C for everything

Simpler: weighted composite for all conditions. Acne spots lose some precision at zone boundaries but the smoothness wins overall.
