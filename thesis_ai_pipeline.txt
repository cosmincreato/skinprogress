AI-Powered Skin Condition Analysis Pipeline
============================================

The skin condition analysis pipeline is structured around three parallel sub-pipelines, one
for each detected condition, each consisting of a heatmap generation stage and an independent
scoring stage. Before any condition-specific processing begins, two shared preprocessing steps
are applied to every input image: face region detection and skin tone masking.


FACE REGION DETECTION
---------------------

Face region detection is performed using the MediaPipe FaceLandmarker Tasks API, which detects
478 three-dimensional facial landmarks from the input image. From these landmarks, a face
silhouette mask is constructed by filling the polygon defined by the 36 outermost landmark
indices, and a face bounding box is computed as the axis-aligned minimum bounding rectangle of
all landmark coordinates. If the landmark model fails to detect a face, the image is
horizontally flipped and detection is retried with the landmark x-coordinates mirrored back
after success. If landmark detection fails entirely, the system falls back to OpenCV's Haar
cascade frontal face detector, and if that also fails, a statistically positioned ellipse
centered at 42 percent of the image height is used. Additionally, the convex hull of 23
landmark indices corresponding to the nostril region is subtracted from the silhouette mask to
prevent the darker interior of the nose from interfering with downstream skin analysis.


SKIN TONE MASKING
-----------------

Skin tone masking converts the image to the YCrCb color space using the standard linear
transformation:

    [FORMULA 1 - enter in Word equation editor]
    Y   = 0.299·R + 0.587·G + 0.114·B
    C_r = 128 + (R - Y)·0.713
    C_b = 128 + (B - Y)·0.564

A pixel is classified as skin if it satisfies all of the following threshold conditions
simultaneously:

    [FORMULA 2 - enter in Word equation editor]
    40 < Y < 240,    130 < C_r < 170,    80 < C_b < 135

These thresholds exploit the property that human skin tones across a wide range of ethnicities
cluster in a compact region of the Cr-Cb plane regardless of overall brightness. Morphological
closing with a 7x7 elliptical kernel is applied afterward to fill small gaps caused by fine
hairs or local lighting variations.


ACNE DETECTION
--------------

For acne detection, heatmap generation and scoring follow separate paths. The heatmap is
produced by cropping the image to the detected face bounding box and running a YOLOv8 model
trained on labeled acne lesion data. Each bounding box returned by the detector is converted
into a two-dimensional Gaussian blob:

    [FORMULA 3 - enter in Word equation editor]
    B_i(x,y) = c_i · exp( -((x - x_i)^2 + (y - y_i)^2) / (2·σ_i^2) )

where c_i is the detection confidence score, (x_i, y_i) is the lesion centroid, and σ_i is
derived from the bounding box dimensions as:

    [FORMULA 4 - enter in Word equation editor]
    r_i = max(6,  (w_i + h_i) / 4 · ρ),    ρ = 0.6
    σ_i = max(6,  r_i / 1.8)

The final acne heatmap is the element-wise maximum across all blobs:

    [FORMULA 5 - enter in Word equation editor]
    H_acne(x,y) = max over i of  B_i(x,y)

If the YOLOv8 detector returns no results, the system falls back to a color-based blemish
detector operating in the HSV color space, identifying pixels with hue in the red and
brownish-red range, saturation above a minimum threshold, and value at least 15 units below the
local neighborhood mean. Connected components above 10 pixels are treated as individual
blemishes, each assigned a per-pixel severity based on local darkness:

    [FORMULA 6 - enter in Word equation editor]
    S_i = clip( 1 - V_i_mean / 255,  0.1,  1.0 )

where V_i_mean is the mean brightness value of the blemish region.

Acne scoring is computed independently from heatmap generation. When at least one blemish is
detected by color analysis, the score is a weighted combination of a count score and an average
severity:

    [FORMULA 7 - enter in Word equation editor]
    Score_count = min( 1.0,  N / 20 )

    [FORMULA 8 - enter in Word equation editor]
    S_mean = (1/N) · sum from i=1 to N of S_i

    [FORMULA 9 - enter in Word equation editor]
    Score_acne = 0.6 · Score_count + 0.4 · S_mean

When no blemishes are found by color analysis, the system falls back to the Skintelligent acne
severity classifier, which outputs probabilities p_i across six discrete severity levels
s_i in {-1, 0, 1, 2, 3, 4}. The continuous score is derived as a probability-weighted
expected severity normalized to the unit interval:

    [FORMULA 10 - enter in Word equation editor]
    E[s] = ( sum of s_i · p_i ) / ( sum of p_i )

    [FORMULA 11 - enter in Word equation editor]
    Score_acne = ( E[s] + 1 ) / 5


REDNESS DETECTION
-----------------

For redness detection, the heatmap is generated by converting the image to the CIELAB color
space and extracting the a* channel, which encodes the green-to-red opponent axis. Because even
healthy skin has a positive a* value due to hemoglobin in the capillaries below the epidermis,
the heatmap is normalized using the 55th and 92nd percentiles of a* values within the detected
skin region, denoted P_55 and P_92:

    [FORMULA 12 - enter in Word equation editor]
    H_redness(x,y) = clip( (a*(x,y) - P_55) / (P_92 - P_55),  0,  1 )

This makes the heatmap relative to each individual's own skin baseline rather than a fixed
absolute threshold. The redness severity score is computed separately using the CLIP
vision-language model in zero-shot classification mode.


UNDER-EYE BAG DETECTION
------------------------

For under-eye bag detection, the heatmap uses facial geometry. Seven MediaPipe landmark indices
around each eye contour are shifted downward to define polygonal regions below each lower
eyelid. Within these regions, grayscale brightness g(x,y) is measured and normalized using the
15th and 55th percentiles P_15 and P_55 of the region, so that darker pixels receive higher
heatmap values:

    [FORMULA 13 - enter in Word equation editor]
    H_bags(x,y) = clip( (P_55 - g(x,y)) / (P_55 - P_15),  0,  1 )

Darker under-eye regions correspond to the shadow cast by prolapsed fat compartments and to
hyperpigmentation from thinned skin revealing underlying vasculature. The under-eye bag
severity score is also computed using CLIP in zero-shot mode.


OVERLAY RENDERING AND DETECTION METADATA
-----------------------------------------

All three heatmaps are rendered as RGBA overlays using a severity color gradient: values below
0.33 map to green, values between 0.33 and 0.67 to yellow, and values above 0.67 to red. The
overlay is composited onto the original photograph using Porter-Duff source-over blending and
returned to the client as a base64-encoded PNG data URL embedded in the JSON response.
Alongside the rendered heatmap, the response includes structured detection metadata containing
the pixel coordinates, radius, and severity of each detected acne spot, and the bounding box
and severity of each redness and under-eye zone. This metadata is used by the frontend to
render hover-sensitive tooltip regions over the overlay image and to drive the vertex coloring
of the three-dimensional face model visualization.
